=== STEP 2: Add a visible debug indicator ===

2a. Add to the existing useEffect inside Hero.tsx — instead of just logging "playing", tick the currentTime to console every 2 seconds for 10 seconds:

    useEffect(() => {
      const v = videoRef.current;
      if (!v) return;
      const onPlay = () => console.log('[hero-video] play event fired');
      const onError = (e: Event) => console.error('[hero-video] error', e);
      v.addEventListener('play', onPlay);
      v.addEventListener('error', onError);
      v.play().catch((err) => console.warn('[hero-video] autoplay blocked:', err));

      const interval = setInterval(() => {
        if (v) {
          console.log('[hero-video] tick — currentTime:', v.currentTime.toFixed(2), 'paused:', v.paused);
        }
      }, 2000);

      return () => {
        clearInterval(interval);
        v.removeEventListener('play', onPlay);
        v.removeEventListener('error', onError);
      };
    }, []);

2b. This logs currentTime every 2 seconds. If currentTime keeps advancing in the console BUT the video still looks frozen visually, we have confirmed proof of GPU paint failure (data progresses, pixels don't repaint). If currentTime stops advancing, video is actually paused/stuck.
